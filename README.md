# SQL Business Analysis Project 1

This project is part of my SQL portfolio.

## Goals
- Clean and explore a real dataset
- Analyze business performance
- Calculate KPIs
- Use PostgreSQL for business insights

## SQL Skills
- SELECT
- JOIN
- GROUP BY
- CASE
- CTEs
- Window Functions
- Data Cleaning

## Business Problem 
An online retail company wants to better undersatand its sales performance, customer behavior, and product performance.

The goal of this project is to analyze retail sales data using PostgreSQL and identify important Business insights that can help management make better decisions.
